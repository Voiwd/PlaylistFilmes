### Features

- Qualquer pessoa pode adicionar uma recomendação de filme sem precisar de login
- Busca por nome, data, autor e ordenação personalizada
- Integração com TMDB e Watchmode API pra disponibilidade, plataforma, preço, entre outros dados sobre os filmes
- Sortear um filme! 🎉
- Ctrl + Alt + 0 para modo admin com senha.
